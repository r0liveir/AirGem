About the project

Flight search with an open model—and deterministic guardrails

AirGem finds practical flights around calendar commitments without asking an LLM to invent availability, prices, or schedule math.

✦

Bounded AI

Gemma parses intent and explains a selected trade-off. SerpApi supplies real flight options, while Python validates constraints and computes the Pareto shortlist.

⌁

Transient by design

Your SerpApi key and optional calendar stay in server memory for up to 30 minutes. They are not written to disk, cookies, HTML, or application logs.

◎

Demo protections

Hashed client-IP ownership isolates sessions, jobs, and booking actions. Per-IP and global limits, bounded inputs, and generic errors reduce abuse and secret exposure.
